Исходники лежат в `../../..` (папка `portfolio`) и **не переименованы** —
их имена и есть описание содержимого. Здесь — только производные

(который разделяется пробелами) и в заголовки кеша, поэтому пробелы

## Как пересобрать производные

Обрезка фигуры делается моделью сегментации, остальное — Pillow.
Важное место: после вырезания у матта остаётся слабая «дымка»
(альфа 1–15) по всему кадру. Её обязательно резать в ноль —
иначе `drop-shadow` размазывает её в светлый прямоугольник вокруг
фигуры, и он отлично виден на тёмном фоне.
