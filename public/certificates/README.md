# Сертификаты — как добавить новый

Вёрстку менять не нужно. Вообще. Два шага.

## 1. Положить файл сюда

Имя строго `NN-slug.ext`, где `NN` — двузначный номер по порядку,
`slug` — короткое латинское имя события, `ext` — `jpg` или `webp`.

```
03-jasyl-qostanai-2026.jpg
```

Требования к файлу:

- длинная сторона **не меньше 1600 px** — иначе в просмотре будет каша;
- `jpg` или `webp`, до ~500 KB;
- скан или ровное фото целиком, без обрезанных краёв: карточка
  показывает документ **целиком**, а не кадрирует его.

## 2. Сделать превью

Превью — тот же кадр шириной 900 px в `webp`, имя с суффиксом
`-preview`:

```
03-jasyl-qostanai-2026-preview.webp
```

Одной командой (нужен Python с Pillow):

```bash
python3 -c "
from PIL import Image
im = Image.open('03-jasyl-qostanai-2026.jpg').convert('RGB')
im.thumbnail((900, 900), Image.LANCZOS)
im.save('03-jasyl-qostanai-2026-preview.webp', 'WEBP', quality=80, method=6)
print(im.size)"
```

Команда напечатает размер превью — он понадобится на шаге 3.

## 3. Поправить одну запись в реестре

Реестр: `src/content/certificates.ts`. Найти запись с этим `id`
и поменять четыре поля:

```ts
{
  id: '03',
  status: 'published',                              // было 'pending'
  file: '03-jasyl-qostanai-2026.jpg',               // было null
  preview: '03-jasyl-qostanai-2026-preview.webp',   // было null
  previewW: 900, previewH: 634,                     // размер из шага 2
  alt: {
    ru: 'Сертификат участника Qostanai Smart City Hackathon, август 2026',
    en: 'Certificate of participation, Qostanai Smart City Hackathon, August 2026',
  },
  note: { ru: '…', en: '…' },                       // что видит посетитель
}
```

Всё. Карточка появится на `/certificates`, на главной и на странице
проекта, к которому она привязана через `projectId`.

## Статусы

| Статус | Что показывает |
|---|---|
| `published` | Обычная стеклянная карточка: превью, клик открывает просмотр |
| `pending` | Пунктирный слот, «Сертификат появится позже», не кликается |
| `festival-only` | Пояснение, что отдельного сертификата под трек нет, есть общий фестивальный, и ссылка на `/events/it-fest-2025` |

`festival-only` задаётся не в записи сертификата, а списком
`festivalOnly` в том же файле: так KZ UniVerse и NPAI ссылаются
на слот `02`, а не заводят себе пустые.

## Про `alt`

`alt` читают вслух скринридеры и видят те, у кого не загрузилась
картинка. «Сертификат» — плохой `alt`. Хороший называет событие
и дату: «Сертификат участника Allur Challenge, ноябрь 2025».
