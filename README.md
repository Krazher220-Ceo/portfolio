# alikhandev.com

Портфолио Алихана Кабдуалы — AI & Web разработчик из Костаная.
Next.js (App Router) + TypeScript, целиком статика, деплой на Vercel.

Раньше в этом репозитории лежали шесть рукописных лендингов проектов
(`/projects/kostanai/jasyl` и остальные). Их разборы переехали сюда,
в страницы проектов, а прежние адреса отдают постоянный редирект —
на `/jasyl` ведут напечатанные QR-коды и публикация в Instagram,
и поменять напечатанное уже нельзя. Сами лендинги остались в истории
и в теге `backup/before-portfolio-merge`.

## Ядро

Три вещи, из которых собран весь сайт: **свет**, **стекло** и
**один выключатель**.

Свет — единственный источник в сцене: он задаёт фон, цвет стекла,
направление теней и положение бликов. Стекло — материал со своими
правилами (толщина, кромка, точечные блики), а не «блюр поверх
картинки». Выключатель — клик по фигуре на первом экране: свет гаснет,
зажигается другим цветом, и вместе с ним меняется язык.

**Тема и язык — одна переменная**, не две:

```
state = 'ru' | 'en'
ru → голубой свет, синее стекло
en → белый свет, чёрное дымчатое стекло
```

Комбинации «синяя тема + английский» не существует. Обе темы тёмные:
разница не «светлая/тёмная», а цветная/монохромная. Светлой темы нет
нигде, кроме печатной версии резюме.

## Как это устроено

| Что | Где | Почему так |
|---|---|---|
| Токены цвета | `src/styles/tokens.css` | Единственный источник цвета. В компонентах цветовых литералов нет: смена темы анимирует сами переменные, хардкод порвал бы кадр |
| Материал стекла | `src/styles/glass.css` | Пять слоёв, три плотности. Больше трёх — иерархия перестаёт читаться |
| Сцена света | `src/components/Scene.tsx` | Конус, дыхание, пылинки, разворот по скроллу |
| Смена света и языка | `src/lib/state.tsx` | Покадровая раскадровка §9: рывок → обрыв → темнота → зажигание → осадка |
| Словари | `src/i18n/` | `ru.json` — эталон ключей, `en.json` объявлен как `typeof ru`: расхождение роняет сборку, а не показывает `undefined` |
| Контент проектов | `src/content/projects.ts` | Только текст из существующих витрин. Ни одной цифры, которой нет в источнике |
| Реестр сертификатов | `src/content/certificates.ts` | Единственное место, которое правится при добавлении файла |

Язык маршрута — правда для сервера: `/ru/*` и `/en/*`, безпрефиксного
корня у страниц нет — `/` только перенаправляет, поэтому ни один адрес
не может означать «какой-то из двух». `data-state` стоит в разметке
ещё до первой отрисовки. Поэтому
вспышки чужой темы не бывает в принципе, а серверный и клиентский
рендер не могут разойтись. Сохранённое предпочтение применяется
блокирующим скриптом в `<head>` — до отрисовки, заменой адреса
на зеркальный.

Переключение языка **не перезагружает страницу и не двигает скролл**:
весь текст подменяется в один кадр полной темноты, поэтому кадра
с перемешанными языками не бывает, а блоки, изменившие размер из-за
разной длины строк, доезжают на места через FLIP.

## Команды

```bash
npm run dev      # разработка
npm run build    # сборка, вся выдача статическая
npm start        # прод-сервер
```

Резюме в PDF печатается из отдельного маршрута — так в файл не может
попасть ни сцена, ни прелоадер, ни рантайм-состояние:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --no-pdf-header-footer --virtual-time-budget=4000 \
  --print-to-pdf=public/resume/alikhan-kabdualy-cv-ru-2026-08.pdf \
  http://localhost:3000/resume/print
```

Дату в имени файла меняем вместе с содержанием: у скачавшего не должна
лежать безымянная `resume.pdf`, а старая версия не должна тянуться
из кеша.

## Что нельзя ломать

- Цвет только через переменные. Ни одного литерала в компонентах.
- Ни одной цифры, которой нет в исходных витринах или в docx.
- Раскрытие при скролле — **один раз**. Повторные раскрытия
  при прокрутке туда-обратно читаются как дешёвый шаблон.
- Фотография ставится только туда, где она действительно снята.
  У проектов без своих кадров обложка — данные, а не чужой кадр.
- `prefers-reduced-motion` — не отключение функций, а другой их вид:
  смена света становится кроссфейдом, раскрытия — только прозрачностью,
  ни одна возможность не теряется.

Подробности про добавление сертификата — `public/certificates/README.md`,
про происхождение картинок — `public/media/README.md`.
