# Проверки перед выкладкой

Скрипты гоняют собранный сайт в headless-браузере. Нужен запущенный
`npm run dev` или `npm start` на :3000.

| Скрипт | Что проверяет |
|---|---|
| `overflow-check.js` | Горизонтальные переполнения и JS-ошибки на 8 страницах × 4 ширины (375/768/1024/1440) |
| `a11y.js` | Клавиатурный проход: виден ли фокус, хватает ли размера цели, есть ли `alt` |
| `motion.js` | Сцена со светом: все ли фазы отрабатывают, не двигается ли скролл, и что происходит при `prefers-reduced-motion` |
| `shot.js` | Скриншот страницы: `node scripts/shot.js <url> <файл> <ширина> <высота> [селектор для прокрутки]` |

`shot.js` останавливает только бесконечные анимации. Пауза на въездных
замораживала их на первом кадре, и элементы выглядели пропавшими —
на этом я один раз уже обманулся.
