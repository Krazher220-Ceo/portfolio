# Ресурсы витрины

Файлы, которые использует `../index.html`.

## Постоянные

| Файл | Назначение |
|---|---|
| `icon-512.png` | иконка приложения — шапка и подвал страницы |
| `favicon-32.png` | значок вкладки браузера |
| `apple-touch-icon.png` | значок при сохранении на домашний экран iOS |
| `og-image.png` | превью при отправке ссылки в мессенджер или соцсеть |

## Опциональные

Страница проверяет наличие этих файлов при загрузке. Файла нет — соответствующая
секция и пункт меню скрыты, посетитель не видит пустых рамок. Файл появился —
секция показывается сама, разметку править не нужно.

| Файл | Секция |
|---|---|
| `certificate.png` | «Сертификат хакатона» |
| `screen-1.png` … `screen-6.png` | «Экраны приложения» |

Порядок проверки расширений: `png` → `jpg` → `jpeg`. Для сертификата
дополнительно проверяется `certificate.pdf` — он встраивается просмотрщиком
браузера.

Скриншоты рассчитаны на вертикальные снимки с телефона, пропорции около 9:16.
Подписи к ним заданы в массиве `SHOTS` в `../index.html`.
